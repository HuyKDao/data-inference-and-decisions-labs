# Data, Inference & Decisions Labs (UC Berkeley Data C102)

Write-ups of the labs I completed in **Data C102: Data, Inference, and Decisions** at UC Berkeley (Fall 2024). The course covers turning data into decisions: hypothesis testing, Bayesian modeling, prediction, causal inference and sequential decision-making.

> **About the code:** the course doesn't allow sharing lab code, so each section explains what I built and what I learned. I'm happy to walk through the code in an interview.

# Hypothesis Testing & Decision Theory (Labs 1–3)

## Lab 1: Review and warm-up
- Measured the speedup of **vectorized NumPy** code over Python loops and discussed when that performance actually matters.
- Explored and cleaned the **Titanic** dataset with pandas and fit a first scikit-learn model.

## Lab 2: Basics of testing
- Plotted null and alternative distributions, then derived and computed **likelihood ratios**.
- Built a **likelihood ratio test (LRT)** and connected it to thresholds on the raw statistic.
- Compared decision rules using **p-values**, significance levels and error rates.

## Lab 3: Loss and risk
- Defined **custom loss functions** for a medical-testing scenario where false negatives and false positives cost different amounts.
- Computed **empirical risk** across significance levels α to find the best threshold.
- Showed how that optimum shifts with **disease prevalence**, then used the framework to make decisions.

## Skills
Hypothesis testing, LRTs, p-values, Type I/II error trade-offs, loss functions, empirical risk, decision theory, NumPy vectorization, SciPy distributions.

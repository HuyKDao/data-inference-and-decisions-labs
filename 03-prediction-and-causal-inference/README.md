# Prediction & Causal Inference (Labs 7–9)

## Lab 7: Nonparametric methods
- Compared **linear regression, decision trees and random forests** on a train/test split, and analyzed the bias-variance trade-off and overfitting.

## Lab 8: Instrumental variables
- Simulated data with an unobserved confounder to show how **naive regression is biased**.
- Estimated the true causal effect with **instrumental variables** and **two-stage least squares (2SLS)**.

## Lab 9: Unconfoundedness
- Reviewed **potential outcomes** and the **average treatment effect (ATE)**.
- Estimated causal effects in a **randomized experiment**, then in observational data using **unconfoundedness** assumptions and adjustment methods.

## Skills
Decision trees, random forests, model comparison, causal inference (potential outcomes, ATE), instrumental variables, 2SLS, confounding, scikit-learn, statsmodels.
